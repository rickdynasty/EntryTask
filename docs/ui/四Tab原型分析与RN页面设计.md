# 四 Tab 原型分析与 RN 页面设计

日期：2026-10-18。依据 `prd/Home.jpg`、`Wealth.jpg`、`Member.jpg`、`Me.jpg` 及 requirements。本文描述本次视觉与页面实现设计，交付验证另见文末，不把设计自动计为实现。

## 原型解读与边界

原图均为 1276×2848 的手机截图，含真实系统栏、五项底栏和截断内容。以内容逻辑宽度 390dp 建立比例参照；实际按设备宽度、字体及安全区适配，不将截图像素直接写成 dp。系统时钟/信号/电量由系统提供；根 Tab 使用既有首页、财富、会员、我的四项及顺序。借钱仅保留我的页营销入口，真实金融动作均进入演示说明。

原型“我的”混合了登录提示及手机号，实施时拆分游客/登录两种状态。游客不显示手机号，不请求个人资产；已登录改为脱敏身份与有效会话数据。截图里的营销数值只作为模拟案例，明确标注演示及业绩口径，不当作真实收益承诺。

## 首页 H-01

1. 暖色背景工具栏：扫码、搜索框、消息、客服。
2. 四大快捷入口；金彩秋冬标题与银杏/山水装饰，独立活动点击区。
3. 白色顶圆角服务面板：两行五列服务、横向服务条。
4. 首次认证营销卡：左侧 RN 文案、右侧礼盒素材。
5. 财富精选：标题/副标题、横向类别、产品指标卡；右侧财富广场转 Native 财富 Tab。

HomeVM 分开订阅首页内容和当前分类产品，内容故障不禁用静态公共工具栏。类别改变更换 query key，旧响应不会覆盖新类别；切回保留类别和滚动位置。服务、活动、产品分别进入受控 RN 子页，金融动作只说明。

## 财富 W-01

顶部财富/资讯分段，公共搜索/消息/客服；财富段包含双资产指标与共享眼睛、市场解读、十项服务、四推荐分类、纯债专区及分享礼。纯债图表用 RN/SVG 原语实现，展示演示数据、统计口径和风险文字，图表按钮为真实控件。

WealthVM 将公开内容、个人资产、当前推荐列表分开：游客仅加载公开内容；资讯段请求资讯列表；推荐变化只换对应资源。资产块点击进入统一资产页；资讯和活动具有列表/详情。营销期限来自 fixture，不按截图日期认定实时状态。

## 会员 M-01

顶部会员/活动/已领权益；欢迎卡采用游客登录 CTA / 已登录等级摘要两态。下方会员专属/能量值乐园；专属中签到卡、3/7日奖励单元和左右不等高营销卡。卡号定制为说明，等级礼遇/好书进入权益详情；活动分段用活动列表，已领权益需认证。

MemberVM 管分段、专属/乐园及提交状态。签到、领取由 Native Mock 返回权威结果，不在 RN 自加能量/库存。签到账本与领取为用户作用域；提交禁重入，成功后刷新会员、我的统计及已领列表。原型普通日基础能量为0，第3/7天额外30/100；无截图的详情按需求字段补稿，不宣称像素级依据。

## 我的 P-01

顶部身份动作+设置/消息/客服；白色身份卡：头像、脱敏手机号/游客提示、低碳标签、欢迎条、五统计。接服务宫格、资产卡、信用卡营销与借钱营销。复用资产事实/掩码，登录后不同时显示“立即登录”。额度和利率仅为营销示例。

ProfileVM 聚合个人资料/统计、资产、公开营销，公开区块不被私人数据失败阻断。统计进入银行卡/待办/卡券/积分/能量只读页；设置含资产偏好与退出，退出取消旧会话资源并恢复游客投影。

## 子页与导航

使用单个 React Navigation native-stack，RootHub 显示四个根页，Native 保留底栏所有权。Native tabSelected/会话变化经 Codegen 事件发送，并在 bootstrap 返回快照；RN 子栈深度回传 Native 控制底栏，避免子页露出底栏。系统返回先给 RN 子栈，再切首页，最后使用既有退出行为。认证通过 Native command 请求，恢复后重新读取会话，不重放写动作。

子页分为产品列表/详情、资讯列表/详情、活动列表/详情、资产/账户/流水、权益/已领/能量、个人资料/事项、服务目录/搜索、消息、设置和统一演示说明。详情使用本地 JSON 文本段落和真实 RN 排版；不打开任意 URL。无目标/无资源显示可返回错误；转账、借款、申卡等无真实交易按钮。

## Mock 与资源

所有本期业务 API 选择 nativeMock：RN → EndpointRegistry → NativeNetwork → Native 拦截 → manifest 对应 JSON；请求后台等待1～3秒，取消/超时独立处理；未知请求拒绝。新增 API 同步 endpoint、schema、manifest 和 fixture，发布构建打入 APK。

公共内容用 per-API JSON，详情及列表的 ID 关联校验。涉及资产/身份由 Native 依据真实会话决定是否可返回；签到/权益/消息写状态由 Native 独立用户键保存，事务完成后才返回，RN 不写 fixture。图片键在 RN 本地白名单映射；只提取用户给定原型的装饰素材，说明来源和限制，不加载外网素材。

## 验收与实施追踪

- 以同一内容宽度和系统字体逐页截图对照原图，检查区域顺序、比例、颜色、间距、文字/图标基线、滚动及固定底栏。金融演示标识、四 Tab 调整和登录态修正属于明确差异。
- 检查首载、刷新、空/错/重试、快速换分类、返回与切 Tab 保留、游客/登录/退出、资产偏好及用户隔离。
- 执行类型/ESLint/架构/契约检查和关键行为测试；Codegen/官方 CLI 启动；检查 APK 中新资源；优化包无 Metro 验证。
- 无单独视觉稿的子页以需求一致和设计系统一致验收。素材取自压缩截图，无法恢复原始矢量/高清源，像素精度与字体差异需据实记录。

实际已实现功能、命令结果与剩余差异在本轮交付记录中列明，不用本设计清单替代验收证据。
